Write a Python program freeslots.py that reads booked time slots from standard input, one per line like 09:00-10:30, and prints the free slots of the working day 08:00-17:00, one per line in the same format. Bookings can overlap, touch each other and come in any order. Include tests in test_freeslots.py and run them with pytest. Write it as a literate program in noweb, in the file freeslots.nw. Tangle it to get freeslots.py and test_freeslots.py.
